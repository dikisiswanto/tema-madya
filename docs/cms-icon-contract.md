# Kontrak Ikon CMS

Sekolahku CMS menyimpan ikon sebagai string Font Awesome. Madya menghormati nilai tersebut.

Contoh:

```text
fas fa-microchip
fas fa-music
fas fa-futbol
fas fa-paint-brush
fa-school
```

Ekstrakurikuler dapat memiliki `icon_color`. Warna hanya diterapkan jika berbentuk hexadecimal enam digit.

Ikon antarmuka milik theme boleh memakai ikon internal Madya. Ikon yang berasal dari data CMS harus diprioritaskan.
