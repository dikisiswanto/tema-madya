## Tema Madya CMS Sekolahku

> **Modern Indonesian School Editorial**
>
> Formal, hangat, berkelas, informatif, fotografi-led, dan human-centered.  
> Madya tidak mengejar tampilan "ultra-minimal", "SaaS", atau "AI-generated". Ia menggabungkan karakter institusional website sekolah Indonesia dengan kualitas editorial modern.

---

## 1. Design Philosophy

Madya dirancang sebagai tema website sekolah yang terasa:

- **terpercaya**, seperti institusi pendidikan resmi;
- **manusiawi**, karena siswa, guru, kegiatan, dan lingkungan sekolah menjadi bagian utama visual;
- **hangat**, tidak terlalu korporat atau dingin;
- **modern**, tanpa mengikuti tren UI yang cepat usang;
- **berkelas**, tetapi tidak mewah secara berlebihan;
- **informatif**, karena website sekolah adalah pusat informasi publik;
- **familiar bagi pengguna Indonesia**, terutama orang tua, siswa, guru, calon siswa, dan masyarakat;
- **ringan**, baik secara visual maupun teknis;
- **konsisten**, meskipun konten berasal dari berbagai modul CMS.

Madya tidak boleh terlihat seperti:

- template WordPress generik;
- dashboard SaaS;
- landing page startup;
- template AI dengan banyak gradient, glassmorphism, blob, dan animasi;
- website korporasi yang terlalu kaku;
- desain ultra-minimal yang terasa kosong;
- kumpulan card yang semuanya memiliki pola identik.

# 2. Visual Character

Karakter visual Madya dibangun dari lima unsur utama:

### 2.1 Institutional

Gunakan:

* navy;
* putih;
* gold sebagai accent;
* typography tegas;
* layout terstruktur;
* alignment yang disiplin;
* metadata yang jelas;
* hierarchy yang kuat.

Hasilnya harus terasa seperti:

> sekolah yang serius, terpercaya, dan terorganisasi.

Bukan seperti:

> startup edtech.

---

### 2.2 Editorial

Layout mengambil pendekatan editorial daripada card-grid generik.

Gunakan:

* headline yang kuat;
* featured story;
* asymmetric composition;
* split layout;
* large photography;
* horizontal story;
* editorial metadata;
* visual hierarchy;
* whitespace yang terkontrol.

Konten harus terlihat seperti sesuatu yang **diceritakan**, bukan sekadar ditampilkan.

---

### 2.3 Human

Manusia harus menjadi salah satu sumber visual utama.

Prioritaskan:

1. siswa;
2. guru;
3. kepala sekolah;
4. kegiatan;
5. interaksi belajar;
6. lingkungan sekolah;
7. fasilitas.

Foto manusia harus memiliki konteks.

Hindari penggunaan:

* avatar generik;
* ilustrasi manusia yang terlalu kartun;
* silhouette stock;
* profile photo yang terlalu kecil.

Untuk directory guru, foto portrait harus cukup besar sehingga wajah dapat dikenali secara visual.

---

### 2.4 Photographic

Fotografi harus menjadi bagian dari storytelling.

Gunakan:

* foto gedung sekolah;
* siswa belajar;
* kegiatan ekstrakurikuler;
* guru;
* prestasi;
* laboratorium;
* perpustakaan;
* kegiatan sosial;
* upacara;
* olahraga;
* kegiatan komunitas.

Photography treatment:

* crop natural;
* aspect ratio konsisten;
* border radius moderat;
* tidak terlalu banyak overlay;
* overlay navy hanya ketika diperlukan untuk readability.

Foto tidak boleh hanya menjadi:

> image placeholder di dalam card.

Foto harus memiliki fungsi editorial.

---

### 2.5 Subtle Depth

Madya bukan flat design murni.

Depth diberikan secara terbatas melalui:

* shadow tipis;
* border;
* layered card;
* offset image;
* overlap;
* soft background surface;
* framed image;
* accent line;
* subtle gradient;
* photography crop.

Gunakan depth secukupnya.

Jangan menggunakan:

* heavy glassmorphism;
* floating cards berlebihan;
* neon glow;
* excessive blur;
* drop shadow besar.

# 19. Three.js

Three.js hanya digunakan untuk **hero ambient visual**.

Tujuan:

> memperkuat identitas sekolah.

Bukan:

> memamerkan teknologi.

Konsep terbaik:

```text
school campus
+
trees
+
main building
+
flag
+
subtle lights
+
small learning nodes
```

Style:

```text
isometric / semi-isometric
minimal geometry
institutional
```

Interaction:

```text
subtle mouse parallax
slow ambient motion
```

Performance rules:

* lazy initialize;
* hanya ketika viewport membutuhkan;
* pause ketika tidak terlihat;
* pause ketika tab tidak aktif;
* respect `prefers-reduced-motion`;
* low pixel ratio;
* dispose ketika route/view selesai;
* jangan terus render ketika idle.

Three.js tidak boleh mengalahkan foto sekolah.

```css
        @apply rounded-2xl border border-slate-200 bg-white;
    }

    .madya-button-primary {
        @apply inline-flex items-center justify-center rounded-xl
            bg-slate-900 px-5 py-3 font-semibold text-white;
    }
}
```

Tetapi:

```text
group
peer
responsive variants
hover variants
```

tetap digunakan langsung sebagai class HTML.

Jangan:

```css
@apply group;
```

karena `group` adalah state marker, bukan utility styling.
