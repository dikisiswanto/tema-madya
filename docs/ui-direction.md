# Arah UI Madya

Madya memakai gaya editorial institusional: tenang, jelas, formal tetapi tetap manusiawi.

## Program dan ekstrakurikuler
CMS menyediakan ikon dan keterangan untuk item ini. Desain menonjolkan ikon, judul, dan deskripsi; jangan mengharapkan gambar per item. Daftar rich component tidak menampilkan tombol “Selengkapnya” jika halaman detail sudah tersedia melalui navigasi CMS.

## Pencarian
Search hanya ditampilkan ketika kemampuan tersebut benar-benar disediakan CMS atau diimplementasikan oleh theme. Search berita memakai parameter search CMS. Halaman download tidak memiliki search palsu.

## Responsif dan aksesibilitas
Konten mengikuti satu site-content container, tidak overflow, memiliki heading hierarchy, focus state, keyboard navigation, label form, accessible name, alt text, dan reduced-motion support.
